# Content Questionnaire

Once you approve the layout, please provide the following so we can replace placeholder content and seed the CMS.

## Profile

- Full name
- Job title (e.g. Full Stack Developer)
- One-line tagline
- Short bio (2–3 sentences for homepage)
- Full bio (1–2 paragraphs for About page)
- Location
- Years of experience
- Profile photo (optional — file or URL)
- Open to work? (yes/no)

## Projects (3–6 items)

For each project:

- Title
- Short summary (1 sentence)
- Full description (2–3 paragraphs)
- Screenshot image (file or URL)
- Tech stack (list)
- Live demo URL (optional)
- GitHub URL (optional)
- Featured on homepage? (yes/no)

## Skills

List grouped by category:

- Frontend
- Backend
- Tools

## Experience

For each role:

- Company name
- Job title
- Start date / end date (or "Present")
- Description (1–2 sentences)

## Social & Contact

- GitHub URL
- LinkedIn URL
- Contact email
- Twitter/X URL (optional)

## Services (when ready)

- **Sanity project ID** — from [sanity.io/manage](https://sanity.io/manage) after creating a project
- **Web3Forms access key** — free at [web3forms.com](https://web3forms.com)
